# Van Life 🚐

A React project created to practice and understand **React Router** concepts.

## 📌 About This Project

Van Life is a learning project built while exploring React Router. The main goal of this project is to practice creating a multi-page React application with client-side routing, nested routes, dynamic routes, and navigation between pages without full page reloads.

This project focuses on improving my understanding of how routing works in modern React applications.

##  Features

* 🏠 **Multiple Pages**
  Built a multi-page user experience using React Router instead of traditional page reloads.

* 🚐 **Van Listing Page**
  Display a collection of vans with basic information.

* 🔍 **Van Detail Pages**
  View individual van information using dynamic routes.

* 🧭 **Client-Side Navigation**
  Navigate between pages smoothly using React Router links.

* 🛣️ **Nested Routes**
  Practice organizing pages with nested routing structures.

* 🔐 **Route Layouts**
  Create shared layouts for different sections of the application.

* ⚡ **Dynamic Routing**
  Use URL parameters to render different content based on the selected van.

* 🎨 **Reusable Components**
  Build reusable React components to keep the code organized.

* 🗂️ **Mock API Data**
  Use MirageJS to simulate backend data during development.

* 📱 **Responsive Design**
  Create a user interface that works across different screen sizes.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/peterpaing/van-life.git
```

Navigate to the project folder:

```bash
cd van-life
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📂 Project Purpose

This project is not intended to be a complete production application. It was created as a hands-on exercise to learn and practice React Router patterns and improve React development skills.

## 📝 Learning Notes

Through this project, I practiced how modern React applications handle navigation, page structure, and user experiences using React Router.
